# pot-plant-mould

Client-side web app that designs concrete plant pots and 3D-printable molds.

## Run

Serve the folder and open it, e.g. `python3 -m http.server`, then visit http://localhost:8000.

## Check

`npm install && npm test` checks the core and wedges for 2, 3, 4 and 6 parts don't overlap.

## Casting

Cast upright: stand the wedges on a board (ply or melamine), slot the tongues into the grooves, clamp (or bolt) the seam ribs and screw the bottom flange down to the board. The board forms the underside of the pot. Then drop the core in so its spokes sit on the seam ribs. Screw each spoke down into its seam, and screw up through the board into the drain pin, so the core can't float. Fill the hollow core with sand for extra weight if you like, and pour through the gaps in the cap above the rim.
