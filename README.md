# pot-plant-mould

Client-side web app that designs concrete plant pots and 3D-printable molds.

## Run

Serve the folder and open it, e.g. `python3 -m http.server`, then visit http://localhost:8000.

## Check

`npm install && npm test` checks the core pieces, spider, drain plug and wedges for 2, 3, 4 and 6 parts don't overlap.

## Casting

Cast upright: stand the wedges on a board (ply or melamine), slot the tongues into the grooves, clamp (or bolt) the seam ribs and screw the bottom flange down to the board. The board forms the underside of the pot. Screw the drain plug to the board through the drain hole (from underneath). Drop the core pieces in one by one, sliding their tongues into the grooves, so their floors seat on the plug's tapered top. Put the spider on top: its lip drops into the core, and its spokes sit on the seam ribs. Screw it into the tab on each core piece and into both ribs of every seam, so the core can't float or spread. Fill the hollow core with sand for extra weight if you like, and pour between the spokes. To demould, unscrew the spider, then slide each core piece straight up.
