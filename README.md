# pot-plant-mould

Client-side web app that designs concrete plant pots and 3D-printable molds.

## Run

Serve the folder and open it, e.g. `python3 -m http.server`, then visit http://localhost:8000.

## Check

`npm install && npm test` checks the core and wedges for 2, 3, 4 and 6 parts don't overlap.

## Casting

Cast upside down: the core's cap sits on the table, the outer wedges stand on the cap, pour into the open pot base.
